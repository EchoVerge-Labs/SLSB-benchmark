## Reading the numbers

Every figure and results table is generated by [`scripts/make_figures.py`](scripts/make_figures.py)
from the CSVs in [`results/`](results/), which are tracked in git. Nothing is transcribed by
hand. Results always state the protocol version they were produced under; scores from
different versions are not comparable.
